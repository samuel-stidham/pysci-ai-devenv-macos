# Kotlin notebook kernel, published to PyPI by JetBrains. It used to come from
# `mamba install -n pysci-ai -c jetbrains kotlin-jupyter-kernel` and vanished
# with conda. It is NOT in nixpkgs under any name, so pip is the only route and
# this file is the right place for it. It needs a JVM at run time, which is why
# devenv.nix declares a JDK rather than borrowing whichever java PATH offers.
